## تشغيل النموذج

١. افتح رابط تشغيل المنصة.
٢. اختر **DEMO / Simulation** ثم **START VIRTUAL SYSTEM TEST**.
٣. تابع حركة كرات التتبع الثلاث على الخريطة، وراجع عدد نقاط التتبع والحزم المستعادة عند اكتمال الاختبار. تظهر هذه المخرجات ضمن بيانات المحاكاة التجريبية.

## تشغيل الكود محليًا

فك ضغط الحزمة وافتح `index.html` في متصفح حديث. يمكنك أيضًا تقديم الملف عبر خادم محلي بالأمر `python3 -m http.server 8000` من مجلد الملف، ثم فتح `http://localhost:8000/`.

الملف `index.html` يحتوي على واجهة المنصة ومنطق الإصدار V110. الفرع `main`، ومعرّف نسخة الكود `505092ad386a33216cbb763e627187a0957ac77f`.
